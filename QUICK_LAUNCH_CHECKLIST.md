# 🚀 Quick Launch Checklist - Just Hype

## 🔑 Verification Setup (Before Launch)
- [ ] Get Google Verification code from GSC
- [ ] Update `src/app/layout.tsx` line ~60:

## 🌐 Launch Day
- [ ] Check website is live
- [ ] Test carousel swipe on mobile

## 📊 Search Engine Setup (Day 1)
1. **Google Search Console**
   - [ ] Go to search.google.com/search-console
   - [ ] Add property with your domain
   - [ ] Verify domain ownership (HTML tag)
   - [ ] Wait for verification (15-30 min)
   - [ ] Submit sitemap: yourdomain.com/sitemap.xml

2. **Bing Webmaster**
   - [ ] Go to bing.com/webmaster
   - [ ] Add site
   - [ ] Verify ownership
   - [ ] Submit sitemap

## ❓ Troubleshooting

**Sitemap not working?**
- Check URL is accessible in browser
- Verify XML format is correct
- Resubmit in GSC

**Not showing in search results?**
- Wait 2-4 weeks minimum
- Verify domain ownership
- Check for crawl errors in GSC
- Ensure robots.txt isn't blocking

**Pages not indexing?**
- Request indexing in GSC
- Check page has content
- Verify no noindex meta tag
- Check redirect chains

**Mobile carousel not working?**
- Test in Chrome DevTools mobile mode
- Test on real device
- Check touch events in browser console
